# Smart Vehicle Contact System

This repository contains the technical foundation for the Smart Vehicle Contact System.

## Local Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Checks

```bash
npm run lint
npm run build
```

## Environment Variables

Copy `.env.example` to `.env.local` when environment values are needed in a later phase.

No database, authentication, vehicle, QR, alert, notification, payment, GPS, AI, IoT, parking, or subscription functionality has been implemented yet.
